# V1.0 setup checklist

## 1. Create the GitHub repo
1. On github.com click **New repository**, name it `ai-security`.
2. Leave it empty: do NOT tick "Add README" or ".gitignore" (the zip already has them).

## 2. Push the skeleton
```bash
unzip ai-security.zip
cd ai-security
git init -b main
git add .
git commit -m "v1.0: project skeleton with MLflow tracking setup"
git remote add origin https://github.com/<your-username>/ai-security.git
git push -u origin main
git tag v1.0
git push origin v1.0
```

## 3. Set up Python
```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

## 4. Check everything works
```bash
pytest -v
```
Expected: all tests pass (6 in total).

## 5. See MLflow in action
```bash
python -c "from src.tracking import start_run; import mlflow; \
r = start_run('smoke-test', 'first-run'); mlflow.log_param('hello','world'); mlflow.log_metric('answer', 42); mlflow.end_run()"
mlflow ui
```
Open http://127.0.0.1:5000. You should see the experiment `ai-security/smoke-test`
with one run, its parameter, metric and the tag `project_version = v1.0`.

## Done when
- [ ] Repo is on GitHub with tag `v1.0`
- [ ] `pytest` passes
- [ ] MLflow UI shows your first run
